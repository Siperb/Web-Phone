## Aggregated Project Documentation

Phone API docs from the sub-projects listed in `PROJECTS_DOCS.md` are aggregated into
`docs/projects/` by the `web-phone-documentation` skill. Each project's `PHONE_API.md` export
manifest drives exactly which files are copied. This repo does not edit those source repos.

To refresh: edit `PROJECTS_DOCS.md` (one absolute repo path per line under `Projects:`) and run
`/web-phone-documentation`. Landing page: `docs/README.md`.

_Last updated: 2026-07-07._
